# Говори свободно · бета 0.2.1

Бесплатный тест тренажёра речи: https://marina-designer.ru/govori-svobodno-beta/

Слово скрыто при открытии. Настройте камеру и нажмите «Получить слово», затем начните запись. Готовое видео содержит слово и таймер. Обработка видео происходит на устройстве; эта сборка не загружает записи на сервер.

Публичный код сжат, без source map; запуск неизменённой сборки ограничен официальным HTTPS-доменом. Это препятствие простому переносу файлов, а не полноценная защита от копирования или серверная проверка доступа. Проверку можно удалить из JavaScript. Ранее опубликованные исходники остаются в истории GitHub.

Старые app.js, core.js, words.js и recorder.js заменены заглушками и не подключаются страницей. Новая страница загружает один app.*.js.

Внутренние проверки пройдены; версия 0.2.0 подтверждена пользователем на телефоне. Проверка именно 0.2.1 на реальном телефоне ещё требуется.
